Double Pronouns: Simple Verbs

Rule 1: If there are two pronouns, the indirect pronoun goes first: me lo, te la, nos los.

Rule 2: le/les + lo/la/los/las changes to se lo, se la, se los, se las.

Example: Doy el libro a Juan → Se lo doy.
